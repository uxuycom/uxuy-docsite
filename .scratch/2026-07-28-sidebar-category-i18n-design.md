# Sidebar Category i18n Design

## Goal

Translate the four visible autogenerated sidebar categories for every non-English locale without changing document routes, hierarchy, or body content.

## Scope

- Keep English labels from the default `docs/*/_category_.json` files.
- Add Docusaurus content-docs translation catalogs for `zh-Hans`, `ja`, `ko`, `vi`, `es`, and `ru`.
- Translate only Perpetual Contracts, Account and Assets, Security and Audits, and Resources.
- Keep the supplemental Contact us category hidden and outside the visible navigation contract.

## Implementation

Generate the translation keys expected by Docusaurus 2.3.1 and populate each locale's `docusaurus-plugin-content-docs/current.json` with the existing approved labels from that locale's `_category_.json` files.

## Verification

- Build all seven locales.
- Inspect each locale's rendered sidebar and assert that none of the four English category labels remain.
- Confirm routes and visible sidebar ordering are unchanged.
