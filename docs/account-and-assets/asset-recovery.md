# Asset Recovery

Asset Recovery applies to certain specific situations, such as when a user transfers a supported asset into a UXUY smart contract account through an incorrect or unsupported deposit path.

## Confirm Before Submitting

- Transaction Hash
- Asset contract address
- Source network and destination network
- Destination address
- Whether the network in question is supported by the UXUY Asset Recovery tool

:::warning Security Notice
Never provide private keys, recovery phrases or verification codes to community members or unofficial support accounts.
:::

For detailed instructions, please refer to the [Asset Recovery Guide](../asset-recovery-guide.md).
