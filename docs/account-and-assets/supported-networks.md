# Supported Networks

UXUY supports deposits, withdrawals and onchain interactions on the following blockchain networks. Network support may change over time, and the information displayed in the App prevails.

| Network | Deposit | Withdrawal | GasLess | Asset Recovery |
| --- | --- | --- | --- | --- |
| Ethereum | Supported | Supported | See [GasLess Rules](./gasless-rules.md) | Supported |
| BNB Smart Chain | Supported | Supported | See [GasLess Rules](./gasless-rules.md) | Supported |
| Base | Supported | Supported | See [GasLess Rules](./gasless-rules.md) | Supported |
| Arbitrum One | Supported | Supported | See [GasLess Rules](./gasless-rules.md) | Supported |
| X Layer | Supported | Supported | See [GasLess Rules](./gasless-rules.md) | Supported |
| Solana | Supported | Supported | See [GasLess Rules](./gasless-rules.md) | Contact support |
| Polygon | Supported | Supported | See [GasLess Rules](./gasless-rules.md) | Supported |
| TRON | Supported | Supported | Not supported | Contact support |

:::note
The networks supported for Asset Recovery do not fully match the networks supported for deposits and withdrawals. The current Asset Recovery Guide lists opBNB, Arbitrum One, Optimism, BNB Smart Chain, Base, Ethereum and X Layer as networks supported for Asset Recovery, but this does not mean that each of these networks supports deposits, withdrawals or all product features for every asset.
:::
