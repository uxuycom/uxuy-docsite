# 資金アカウント

資金アカウントは、ユーザーが UXUY のサポート対象資産を確認・管理するための主要な入口です。

資金アカウントでは、以下の操作が可能です。

- サポート対象の各資産の残高を確認する
- 外部ウォレットまたは取引プラットフォームから資産を入金する
- 外部アドレスへ資産を出金する
- 利用可能な UXUY のプロダクトアカウント間で資産を振替する
- 提供されている場合、サポート対象の法定通貨または第三者の入金チャネルを利用する

入金と出金の具体的な操作手順は、[クイックスタート](../getting-started.md#deposits-and-withdrawals) をご参照ください。
