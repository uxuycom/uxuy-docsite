# 資産回収

資産回収機能は、ユーザーが誤ったまたはサポート対象外の入金経路を通じて、サポート対象資産を UXUY のスマートコントラクトアカウントへ送付した場合など、特定の状況に適用されます。

## 申請前にご確認ください

- トランザクションハッシュ（Transaction Hash）
- 資産のコントラクトアドレス
- 送金元ネットワークと送金先ネットワーク
- 送金先アドレス
- 該当ネットワークが UXUY の資産回収ツールでサポートされているか

:::warning セキュリティに関する注意
コミュニティメンバーや非公式のカスタマーサポートアカウントに対して、秘密鍵、リカバリーフレーズ、認証コードを提供しないでください。
:::

詳細な操作手順は[『資産回収ガイド』](../asset-recovery-guide.md)をご参照ください。
