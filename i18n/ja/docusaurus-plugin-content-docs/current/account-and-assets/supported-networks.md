# サポート対象ネットワーク

UXUY は以下のブロックチェーンネットワークにおいて、入金、出金、オンチェーンでのやり取りに対応しています。ネットワークの対応範囲は随時変更される場合があり、最終的には App 内に表示される内容が優先されます。

| ネットワーク | 入金 | 出金 | GasLess | 資産回収 |
| --- | --- | --- | --- | --- |
| Ethereum | 対応 | 対応 | [GasLess ルール](./gasless-rules.md) をご参照ください | 対応 |
| BNB Smart Chain | 対応 | 対応 | [GasLess ルール](./gasless-rules.md) をご参照ください | 対応 |
| Base | 対応 | 対応 | [GasLess ルール](./gasless-rules.md) をご参照ください | 対応 |
| Arbitrum One | 対応 | 対応 | [GasLess ルール](./gasless-rules.md) をご参照ください | 対応 |
| X Layer | 対応 | 対応 | [GasLess ルール](./gasless-rules.md) をご参照ください | 対応 |
| Solana | 対応 | 対応 | [GasLess ルール](./gasless-rules.md) をご参照ください | カスタマーサポートへお問い合わせください |
| Polygon | 対応 | 対応 | [GasLess ルール](./gasless-rules.md) をご参照ください | 対応 |
| TRON | 対応 | 対応 | 非対応 | カスタマーサポートへお問い合わせください |

:::note
資産回収に対応するネットワークは、入金・出金に対応するネットワークと完全には一致しません。現行の『資産回収ガイド』では、opBNB、Arbitrum One、Optimism、BNB Smart Chain、Base、Ethereum、X Layer が資産回収に対応するネットワークとして挙げられていますが、これは上記の各ネットワークがすべての資産の入金、出金、またはすべてのプロダクト機能に対応していることを意味するものではありません。
:::
