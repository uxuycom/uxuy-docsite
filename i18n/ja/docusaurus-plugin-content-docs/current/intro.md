# プロダクト概要

## UXUY とは

UXUY は **Binance Labs のインキュベーションを受け、YZi Labs が出資する**ステーブルコインネイティブのオンチェーン取引プラットフォームです。ユーザーはステーブルコインを保有するだけで、同一のアカウント・同一のインターフェース上で暗号資産、無期限先物、株式、現実資産（RWA）を取引でき、複数のネットワーク、ウォレット、クロスチェーンブリッジ、取引プロトコルを手動で切り替える必要はありません。

UXUY はスマートコントラクトアカウント、GasLess、クロスチェーンルーティング、オンチェーン決済を 1 つの統合された体験としてまとめ、ステーブルコインによる **「U であらゆるものを買う」** というビジョンを実現します。チェーンの選択、Gas の管理、クロスチェーンルーティングはプロトコルがバックグラウンドで自動的に処理し、すべての取引記録は常にオンチェーンで公開検証できます。

トレーダーは UXUY App または Web の統合インターフェースから資産を管理し、さまざまなタイプの取引マーケットにアクセスできます。

## UXUY の特長

- **ステーブルコインネイティブ**：ステーブルコインを統一の価格表示・決済手段として使用するため、チェーンごとにネイティブトークンを準備したり、複数のウォレットを管理する必要がありません。
- **1 つのアカウントで複数のマーケットへ**：暗号資産、無期限先物、株式、RWA を同一のアカウントとインターフェース内で完結でき、異なるプラットフォーム間で資産を移動する必要がありません。
- **クロスチェーン自動ルーティング**：システムが流動性、価格、スリッページ、ネットワークコストを自動的に評価し、実行可能な取引経路を探索します。ユーザーが手動でチェーンを選択したり、ブリッジを利用する必要はありません。
- **オンチェーンで検証可能**：決済記録は公開されたブロックチェーン上に記録され、ユーザーはブロックエクスプローラーを通じて取引および資金の移動を独自に検証できます。

## UXUY でできること

- サポート対象のブロックチェーンネットワーク間で暗号資産を取引する
- レバレッジを利用して無期限先物を取引する
- オンチェーンで株式および現実資産（RWA）マーケットに参加する
- サポート対象資産の入金、振替、出金を行う
- クロスチェーンルーティングにより、ネットワークを手動で切り替えずに取引を完了する

:::note
個別のプロダクトおよびマーケットの提供範囲は、地域やプラットフォームのバージョンによって異なる場合があります。
:::

## 主な機能

### 1 つのアカウントで複数のマーケットに接続

ユーザーは 1 つの UXUY アカウントと統合インターフェースから、暗号資産、無期限先物、株式、RWA などのさまざまなマーケットにアクセスできます。

### GasLess 体験

条件を満たす取引について、UXUY はブロックチェーンネットワークの Gas 要件を抽象化して処理します。これにより、ユーザーはサポート対象の各ネットワークでネイティブ Gas トークンを個別に保有していなくても、オンチェーンでのやり取りを完了できます。

適用条件、最低取引金額、サポート対象ネットワークは異なる場合があり、最終的な費用はユーザーが取引を確認する前に画面に表示される情報が優先されます。詳細は [GasLess ルール](./account-and-assets/gasless-rules.md) をご参照ください。

### クロスチェーン資産ルーティング

UXUY は、サポート対象ネットワークにおけるユーザーの利用可能残高と実行可能な経路を識別します。ユーザーが取引を送信すると、システムは利用可能な流動性、価格、スリッページ、ネットワークコスト、ルーティング状況を総合的に評価した上で、対応する取引を実行します。

### スマートコントラクトアカウント

UXUY はスマートコントラクトアカウントのインフラを採用しており、ウォレット作成やオンチェーン操作のプロセスを簡素化しながら、透明で検証可能なブロックチェーン決済記録を保持します。

### オンチェーン決済

取引は、サポート対象のブロックチェーンネットワークまたはプロトコルを通じて執行・決済されます。該当する場合、ユーザーは対応するブロックエクスプローラーで関連する取引記録を照会・検証できます。
