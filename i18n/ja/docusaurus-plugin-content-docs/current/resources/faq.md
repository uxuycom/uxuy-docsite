# よくあるご質問

## UXUY を利用するにはネットワークのネイティブ Gas トークンを保有する必要がありますか

条件を満たす取引では UXUY の GasLess 体験を利用できます。対応の有無は、画面に表示されるネットワーク、資産、取引金額、プロダクトの条件によって決まります。詳細は [GasLess ルール](../account-and-assets/gasless-rules.md) をご参照ください。

## 実際の約定価格が想定価格と異なるのはなぜですか

市場の変動、流動性、スリッページ、ルーティングの変更、一部約定、ネットワークの状況などにより、最終的な約定価格が想定価格と異なる場合があります。

## 無期限先物のポジションが強制決済されたのはなぜですか

口座の証拠金が維持証拠金の要件を満たせなくなった場合、ポジションは強制決済（ロスカット）される可能性があります。レバレッジ倍率、未実現損失、ファンディングコスト、手数料、リスクティアの変動はいずれも強制決済リスクに影響し得ます。詳細は [証拠金と強制決済](../perpetuals/margin-and-liquidation.md) をご参照ください。

## 画面に表示される強制決済価格が変動するのはなぜですか

ポジションの調整、手数料の控除、ファンディングコストの決済、レバレッジ倍率の変更、適用されるリスクティアの変動により、強制決済価格も変動する可能性があります。

## 誤ったネットワークで入金した場合はどうすればよいですか

送金をすぐに繰り返して送信しないでください。まずトランザクションハッシュを保存し、UXUY の公式カスタマーサポートを通じてサポートをお求めください。該当ネットワークおよび状況がサポート対象である場合は、公式の [資産回収](../account-and-assets/asset-recovery.md) ツールもご利用いただけます。

## ドキュメントと App の表示が一致しない場合、どちらが優先されますか

UXUY のプロダクト画面にリアルタイムで表示されるパラメータおよび確認情報が優先されます。プロダクトのルールが変更された場合は、関連ドキュメントも速やかに更新されます。
