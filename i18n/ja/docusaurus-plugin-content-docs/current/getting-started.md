# クイックスタート

## ダウンロードと登録

UXUY は必ず公式ウェブサイトまたは認証済みのアプリストアページからダウンロードし、非公式のチャネルで共有されたインストールリンクは使用しないでください。

公式ダウンロードページ：[https://www.uxuy.com/download](https://www.uxuy.com/download)

### アカウントの作成

UXUY は以下のログイン方法に対応しています。

- Apple ID
- Google アカウント
- メール認証コード

画面の案内に従ってアカウント作成を完了し、UXUY App に進んでください。

:::warning セキュリティに関する注意
- 現在アクセスしているのが UXUY の公式ドメインまたは公式アプリであることを確認してください。
- 認証コード、秘密鍵、リカバリーフレーズ、アカウント復旧情報を第三者に開示しないでください。
- UXUY の公式カスタマーサポートが、不明なアドレスへの資産送付をユーザーに求めることはありません。
:::

## 入金と出金 {#deposits-and-withdrawals}

### 資産の入金

1. UXUY を開き、【資産】または【資金】ページに移動します。
2. 【入金】を選択します。
3. 入金する資産とネットワークを選択します。
4. 入金アドレスをコピーするか、QR コードをスキャンします。
5. 外部ウォレットまたは取引プラットフォームから、当該アドレスへ資産を送付します。

:::danger 重要なご注意
UXUY で選択した資産とネットワークが、送金元プラットフォームと完全に一致していることを必ず確認してください。サポート対象外のネットワークで入金した場合、着金の遅延や、資産が回収できない事態につながる可能性があります。
:::

### 資産の出金

1. UXUY を開き、【資産】または【資金】ページに移動します。
2. 【出金】を選択します。
3. 出金する資産とネットワークを選択します。
4. 受取アドレスと出金数量を入力します。
5. ネットワーク、手数料、受取アドレスに誤りがないことを確認して送信します。

出金機能の提供状況、処理時間、関連費用は、資産およびネットワークによって異なる場合があります。

## 初回取引を完了する

1. UXUY アカウントにサポート対象の資産を入金します。
2. 【取引】ページに移動します。
3. 取引したいマーケットまたは資産を選択します。
4. 取引数量を入力します。
5. 想定約定価格、手数料、スリッページ、執行ルートを確認します。
6. 内容を確認して取引を送信します。
7. 注文履歴またはオンチェーンの取引記録で結果を確認します。

:::note
レバレッジ商品を利用する前に、証拠金、強制決済（ロスカット）、ファンディングレートなどの内容を十分にご理解ください。詳細は [無期限先物](./perpetuals/overview.md) をご参照ください。
:::
