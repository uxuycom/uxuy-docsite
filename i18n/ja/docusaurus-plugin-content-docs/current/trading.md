# 取引

## 取引の概要

UXUY は統合インターフェースを通じて、さまざまなオンチェーンマーケットへの取引入口を提供します。

## 暗号資産取引

ユーザーはアカウント内の利用可能なステーブルコイン残高を使って、サポート対象の暗号資産を取引できます。UXUY は実行可能な取引経路を探索するため、複数のサポート対象ネットワークや流動性ソースの間でルーティングを行う場合があります。

取引を確認する前に、以下の項目を重点的にご確認ください。

- 想定約定価格
- 価格インパクトとスリッページ
- 取引手数料およびネットワーク手数料
- 最低受取数量
- 選択された執行ルートとネットワーク

## 無期限先物

ユーザーは証拠金とレバレッジを利用して無期限先物（パーペチュアル契約）を取引できます。無期限先物には決められた満期日がありませんが、ポジションの保有によりファンディングコストが発生する場合があります。また、口座の証拠金が不足した場合、ポジションは強制決済（ロスカット）される可能性があります。

詳細なルールは [無期限先物](./perpetuals/overview.md) をご参照ください。

## 株式と RWA

UXUY は、サポート対象の株式連動資産および現実資産（RWA）のオンチェーンマーケットへの入口を提供します。プロダクトによって、取引時間、流動性、価格形成メカニズム、決済構造、地域ごとの提供状況が異なる場合があります。

:::note
主要マーケットの取引時間外は流動性が低下し、売買スプレッドや価格インパクトが拡大する場合があります。
:::

## コピートレード

コピートレードでは、条件を満たすトレーダーをフォローし、ユーザーが設定したコピー条件に従って、選択した取引行動を自動的に複製できます。

コピートレード機能の提供状況およびその執行インフラは、現在の UXUY App に表示されているプロダクトのバージョンが優先されます。
