## 資金の安全性

- **コールド・ホットウォレットの分離**：プラットフォームの資金は、ホット側の資金保管庫（Hot Vault）とコールド側の資金保管庫（Cold Vault）に分けて保管されています。詳細は [コントラクトとインフラのアドレス](./contracts-and-addresses.md) をご参照ください。
- **保険基金**：極端な相場環境における強制決済の損失超過リスクに対するバッファを提供します。詳細は [保険基金と自動デレバレッジ（ADL）](../perpetuals/insurance-fund-and-adl.md) をご参照ください。
