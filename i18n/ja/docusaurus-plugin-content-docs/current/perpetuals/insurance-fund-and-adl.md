# 保険基金と自動デレバレッジ（ADL）

## 保険基金

### 保険基金とは

保険基金は、極端な市場変動および強制決済による損失超過リスクに対応するためのリスク保全メカニズムです。強制決済対象のポジションが、関連する損失をカバーできる価格で決済を完了できない場合、保険基金がプラットフォームのルールに従って優先的に当該損失を負担し、リスクが他のユーザーへ波及する可能性を低減します。

保険基金は、マーケットのリスク耐性を高め、自動デレバレッジ（ADL）の発動確率を低減することに寄与します。

### 保険基金の原資

- 強制決済注文が破産価格より有利な価格で約定した際に生じる余剰資金
- プラットフォームが適用ルールに従って繰り入れるリスク準備資金
- その他、プラットフォームのルールに適合するリスク補填資金

:::note
契約マーケットや取引ペアごとに保険基金が独立して管理される場合があります。具体的な取り扱いは UXUY の実際のプロダクトルールが優先されます。
:::

### 保険基金の用途

- 強制決済注文により発生した損失超過分の補填
- 自動デレバレッジ（ADL）の発動確率の低減
- マーケットのリスク耐性の向上
- 極端な相場環境における取引システムの安定稼働の確保

## 自動デレバレッジ（ADL）

### ADL とは

ADL（Auto Deleveraging、自動デレバレッジ）は、極端な相場環境における最終段階のリスク管理メカニズムです。強制決済注文が十分に約定せず損失超過が発生し、かつ保険基金でその損失全額をカバーできない場合、プラットフォームはリスク順位に従って一部の利益ポジションに対して自動デレバレッジを実行し、取引システム全体の安定を維持することがあります。

### ADL が発動する理由

- 強制決済注文が完全に約定しない
- 強制決済後に損失超過が発生する
- 保険基金が当該損失をカバーできない

### ADL キューに入りやすいポジション

プラットフォームは通常、定められたリスクルールに従ってポジションを順位付けします。順位に影響し得る要素には、利益水準、実効レバレッジ、保有規模などが含まれます。具体的な順位付け指標および実行ルールは UXUY のプロダクト仕様が優先されます。

### ADL 発生後の取り扱い

- ポジションの一部または全部が自動的に縮小または決済される可能性があります
- 縮小された部分の実現損益は決済されます
- 縮小されなかった残りのポジションは、引き続き保有できます（該当する場合）
- ユーザーは取引履歴またはプラットフォームの通知から関連する結果を確認できます
