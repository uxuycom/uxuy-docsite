# リスクリミットとポジションティア

## ポジションティアとは

保有規模ごとに異なるマーケットリスクを管理するため、プラットフォームはポジション想定元本に応じてポジションを異なるリスクティアに区分し、各ティアに対応するリスクパラメータを設定します。

## ポジションティアを設ける理由

保有規模が拡大するにつれ、極端な相場環境における流動性リスクや強制決済リスクも高まる可能性があります。そのため、大口ポジションには通常、以下のようなより厳格なリスク制約が適用されます。

- より高い証拠金要件
- より低い利用可能な最大レバレッジ
- より厳格な維持証拠金およびリスク管理パラメータ

## ティアの変動

ポジションティアは、ポジション想定元本の変動に応じて動的に調整されます。

- ポジションが増加した場合、より高いリスクティアに移行する可能性があります。
- ポジションが減少した場合、より低いリスクティアに戻る可能性があります。

ティアが変動した後は、利用可能な最大レバレッジ、維持証拠金率、その他の適用されるリスクパラメータも同時に調整される場合があります。具体的なティアとパラメータは、UXUY の取引画面に表示される内容が優先されます。
