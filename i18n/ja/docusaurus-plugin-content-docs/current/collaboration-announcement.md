# UXUY Wallet プロジェクト提携のお知らせ

UXUY Wallet は、ウォレットおよび関連 DApp を軸としたエコシステム提携を行っており、プロジェクトチームに対してプロジェクトの掲載、ライブ配信でのインタラクション、オフラインでの交流などのサポートを提供し、ユーザーがエコシステムのプロジェクトを理解できるよう支援します。

リソースへの掲載やイベントへの参加それ自体は、UXUY Wallet が当該プロジェクトへの投資・保証・リターンの約束を行うことを意味するものではありません。提携の範囲は、両者が確認した具体的な事項に限られます。

## 提携の形式

|提携形式|主な内容|
|---|---|
|人気 DApp 掲載|プロジェクトチームは、ウォレットの人気 DApp エリアへの掲載を申請できます。所要の資料を提出し、審査および提携条件を満たす必要があります。|
|バナー掲載|プロジェクト審査および関連する提携条件を満たすプロジェクトは、バナー掲載を申請できます。バナー掲載と人気 DApp 掲載は、それぞれ別途申請が必要です。|
|ライブ配信提携|プロジェクトチームは自らライブ配信を行い、UXUY Wallet と連携してユーザーとのインタラクションやアクティブ化の運営を進めることができます。|
|オフライン AMA|関連する提携条件を満たすプロジェクトは、プロジェクトユーザー向けのオフライン交流を申請できます。日時・場所・具体的な進行は両者間の協議により決定します。|

リソースごとに、申請条件・掲載期間・実施内容は異なります。詳細は UXUY Wallet の提携担当者にお問い合わせください。申請の提出は、提携資格や掲載リソースの付与が確定したことを意味するものではありません。掲載位置と順位は運営側の判断で配置され、掲載期間中に変更される場合があります。UXUY Wallet は、固定の順位、特定のトラフィック・ユーザー増加・取引効果を約束するものではありません。

ライブ配信提携に UXUY Wallet 提供の体験金が含まれる場合、UXUY Wallet は約定した範囲内でその配布を担当します。具体的な金額、配布時期および使用上の制限については、該当するイベントのルールをご確認ください。

## 申請と審査

プロジェクトチームは、UXUY Wallet の提携担当者に申請希望のリソースを伝え、プロジェクトの状況に応じて、プロジェクト資料、DApp への入口、デプロイ済みコントラクトの情報、その他の検証に必要な資料を提出します。プロジェクトの LP プール条件に関わる申請では、対象チェーン、プールアドレスおよび関連資金の検証情報を提供する必要があります。

人気 DApp 掲載の申請には、現時点でデプロイ済みのコントラクトを対象とする監査レポートの提出が必須であり、関連する監査およびプロダクト検証の要件を満たす必要があります。UXUY Wallet は、プロダクトの中核フローおよび関連する資金の引き出し経路を確認します。その他のリソースについて監査レポートが必要かどうかは、プロジェクトごとに判断します。これらの審査・検証は提携可否の判断のために行うものであり、プロジェクトの継続的な安全性・合法性・コンプライアンス遵守や資金の引き出しを保証するものではありません。

審査通過後、両者は具体的な提携事項と実施内容を確認し、実際のスケジュールに沿って進めます。また、リソースの種類に応じて提携効果を確認し、今後の対応を協議します。

UXUY Wallet は、両者が確認した範囲内で掲載、ユーザー運営およびイベント支援を提供します。プロジェクトチームは、自ら提供するプロジェクト資料、宣伝内容、プロダクト、コントラクトおよび関連サービスについて、法令上負うべき責任を負います。プロジェクトチームの見解・発言・行動は、UXUY Wallet の公式な立場を代表するものではありません。
