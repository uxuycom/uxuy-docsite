# UXUY プライバシーポリシー

本プライバシーポリシーは、お客様が本アプリを利用される際に、UXUY（本プライバシーポリシーにおいて「アプリ（App）」、「当社（Company）」、「サービス（Services）」、「私たち（We）」、「当方（Us）」または「当社の（Our）」といいます）がどのように情報を収集するか（個別にまたは総称して「本サービス（Services）」といいます）を説明するものです。また、お客様から収集した情報を当社がどのように利用および開示するか、ならびに当該情報に関するお客様の権利についても説明します。

本サービスにアクセス、閲覧または利用することにより、お客様は、本プライバシーポリシーに記載のとおり、当社がお客様の情報を収集、保存、利用および開示することに明示的に同意したものとみなされます。本プライバシーポリシーの内容に同意いただけない場合は、本サービスを利用しないでください。

## 本サービスを通じて収集される情報およびお客様が直接かつ自発的に当社へ提供する情報

お客様が本アプリのユーザーである場合、カスタマーサービスやテクニカルサービスなど当社のいずれかの部門と連絡を取る際に、お客様が当社に提供する情報を収集することがあります。本サービスへのアクセスのためにサインアップされる場合、登録手続きの一環として、メールアドレスその他の個人情報または非個人情報の提供を求められることがあります。

## 本サービスを通じて自動的に収集される情報

お客様が本サービスを利用される際、当社はお客様に関する情報を自動的に収集します。モバイルデバイスから本サービスにアクセスされる場合、当社はお客様のモバイルデバイスのおおよその位置を特定できることがあります。当社は、お客様のモバイルデバイスのブランド、機種、オペレーティングシステム、解像度、画面サイズ、システムバージョン、Bluetooth 設定、インターネット接続、モバイルデバイスの Android 広告 ID、IP アドレス、モバイル国コード、およびお客様の身元情報を含みますが、これらに限られない情報を収集します。また、お客様の写真、メディアおよびファイル、デバイスのカメラ、Wi-Fi 接続情報、ならびにデバイス ID へのアクセスを求めることがあります。

お客様は、モバイルデバイスの設定を調整することにより、お客様のデバイス（コンピューター、スマートフォンまたはタブレット）から当社が収集する情報の量を制限できる場合があります。

当社は、本サービスを通じて収集した情報を、本サービスならびに当社の製品およびサービスがどのように利用されているかをより深く理解するために利用します。利用状況のパターンや傾向を特定することにより、本サービスならびに当社の製品およびサービスをより良く設計し、お客様の体験を向上させることができます。また、以下に記載のとおり、これらの情報を商業目的およびマーケティング目的で利用することもあります。

## 個人データの保護

### データ管理者

データ管理者（Data Controller）とは、個人データが処理される目的および方法を決定する自然人または法人をいいます。本プライバシーポリシーおよびケイマン諸島データ保護法（DPL）の文脈において、データ管理者は UXUY であり、個人データの収集、利用および保護について責任を負います。

### データ処理者

データ処理者（Data Processor）とは、データ管理者に代わって個人データを処理する自然人または法人をいいます。特定の状況において、当社は、サービスの提供および個人データの処理を支援するため、第三者サービスプロバイダーをデータ処理者として起用することがあります。

### 個人データ

個人データ（Personal Data）とは、識別されたまたは識別可能な個人に関する一切の情報をいいます。これには、氏名、連絡先情報、身元確認情報、財務情報、雇用情報、技術データ、および個人を直接的または間接的に識別できるその他のデータが含まれますが、これらに限られません。

### 処理

処理（Processing）とは、自動的な手段によるか否かを問わず、個人データに対して行われる一切の操作または一連の操作をいい、収集、記録、整理、構造化、保存、適合、変更、検索、参照、利用、送信による開示、頒布、照合、結合、制限、消去または破壊などが含まれます。

### 処理の法的根拠

ケイマン諸島 DPA の下では、個人データは、適法な根拠がある場合に限り処理することができます。法的根拠には、同意、契約上の必要性、法的義務の遵守、または正当な利益の追求（ただし、当該利益が個人の権利および自由に優先されない場合に限ります）が含まれます。

### データ主体の権利

個人は、データ主体（Data Subject）として、ケイマン諸島 DPA の下で以下を含む一定の権利を有します。

1. **アクセス権**：自己に関する個人データが処理されているか否かの確認を得る権利、および処理されている場合に当該個人データにアクセスする権利。

2. **訂正権**：不正確な個人データの訂正を求める権利。

3. **消去権**：データが収集された目的にとってもはや必要でなくなった場合など、特定の状況において個人データの削除を求める権利。ご希望の場合は、以下の手順に従って、当社アプリ内でアカウント（すべての個人情報およびアカウントプロファイルを含みます）を削除できます。
   - 3.1）「アカウントプロファイル」の「セキュリティ」に進み、「アカウント管理」をクリックします
   - 3.2）「アカウント管理」内の「アカウント削除」をクリックします。上記の手順を完了できなかった場合は、当社チーム contact@uxuy.com までご連絡いただければ、さらにサポートいたします。

4. **処理の制限を求める権利**：個人データの正確性に異議がある場合など、一定の状況において処理の制限を求める権利。

5. **データポータビリティの権利**：構造化され、一般的に利用され、機械可読な形式で個人データを受け取る権利、および当該データを他のデータ管理者に移転する権利。

6. **異議申立ての権利**：正当な利益に基づく処理またはダイレクトマーケティング目的の処理を含む一定の状況において、個人データの処理に異議を申し立てる権利。

### データセキュリティ

UXUY は、個人データのセキュリティおよび機密性を確保するため、適切な技術的および組織的措置を実施することに努めます。これらの措置は、個人データを不正なアクセス、開示、改変および破壊から保護するために設計されています。

### データの移転

特定の状況において、個人データは、ケイマン諸島外のデータ処理者を含む第三者に移転されることがあります。かかる移転は、ケイマン諸島 DPA の要求に従い、個人データの保護を確保するための適切な保護措置の対象となります。

個人の権利および自由にリスクをもたらすおそれのあるデータ侵害が発生した場合、UXUY は、ケイマン諸島 DPA の要件に従い、関連する監督当局に対し、また必要に応じて影響を受ける個人に対し、速やかに通知します。

### 個人データの保持

個人データは、収集された目的の達成に必要な期間、または適用される法令により要求される期間、保持されます。
