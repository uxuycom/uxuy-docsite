# Обзор бессрочных контрактов

Бессрочные контракты позволяют пользователям открывать длинные или короткие позиции по поддерживаемым рынкам без фиксированной даты экспирации.

- При росте рыночной цены длинная позиция может приносить прибыль.
- При падении рыночной цены короткая позиция может приносить прибыль.
- Кредитное плечо увеличивает рыночную экспозицию при том же объёме маржи, но одновременно пропорционально увеличивает риск.
- Если позиция не соответствует требованиям по поддерживающей марже, может быть инициирована принудительная ликвидация.
- Механизм ставки финансирования служит для максимального приближения цены бессрочного контракта к цене базового рынка.

## Что нужно знать до начала торговли

Перед размещением заявки проверьте следующую информацию:

- Инструмент контракта и направление позиции
- Тип заявки и цена заявки
- Объём позиции
- Размер кредитного плеча
- Ожидаемая маржа и комиссия за открытие позиции
- Ожидаемая цена принудительной ликвидации
- Ставка финансирования и расчёты по ней

## Правила расчёта цены заявок

При оценке маржи применяется следующее:

- Расчётная цена для **лимитной заявки**: цена лимитной заявки, указанная пользователем.
- Расчётная цена для **рыночной заявки**: маркировочная цена на момент отправки заявки.

Фактическая маржа и комиссии рассчитываются исходя из фактически исполненного объёма, цены исполнения, размера кредитного плеча и применимой ставки комиссии Maker или Taker.

## Определения ключевых показателей

| Термин | Описание |
| --- | --- |
| Маркировочная цена (Mark Price) | Справочная цена, используемая для расчёта нереализованной прибыли и убытка, контроля состояния маржи и выполнения расчётов, связанных с принудительной ликвидацией. |
| Средняя цена открытия (Entry Price) | Средняя цена сделок по текущей позиции, взвешенная по объёму исполнения. |
| Номинальная стоимость позиции (Position Notional) | Номинальная стоимость, полученная умножением объёма позиции на соответствующую справочную цену. |
| Начальная маржа (Initial Margin) | Маржа, необходимая для открытия и поддержания первоначальной экспозиции позиции. |
| Поддерживающая маржа (Maintenance Margin) | Минимальная маржа, необходимая для того, чтобы позиция не была принудительно ликвидирована. |
| Собственный капитал счёта (Account Equity) | Сумма баланса кошелька и всей нереализованной прибыли и убытка. |
| Ставка финансирования (Funding Rate) | Ставка, применяемая при обмене средствами между длинными и короткими позициями с фиксированной периодичностью. |
| Уровень риска (Risk Tier) | Уровень риска, определяемый по номинальной стоимости позиции и используемый для установления максимально доступного кредитного плеча, ставки поддерживающей маржи и других параметров риска. |
| Страховой фонд (Insurance Fund) | Механизм защиты от риска, предназначенный для покрытия части убытков при ликвидации с отрицательным балансом в условиях экстремального рынка и для снижения вероятности срабатывания автоматического сокращения позиций (ADL). |
| Автоматическое сокращение позиций (ADL) | Механизм контроля риска последнего уровня, при котором платформа может автоматически сокращать часть прибыльных позиций согласно ранжированию по риску, если убытки от ликвидации не могут быть полностью покрыты страховым фондом. |
