# Маржа, прибыль и убыток, механизм принудительной ликвидации

:::info
При расхождении содержания документации с данными, отображаемыми в торговом интерфейсе UXUY, приоритет имеют актуальные данные и правила в интерфейсе продукта. Фактический расчёт может дополнительно учитывать специфические для продукта правила точности и округления, резервирование комиссий, финансирование, уровни риска и другие параметры.
:::

## Маржа и стоимость открытия позиции

### Ожидаемая маржа при открытии позиции

```
Ожидаемая маржа при открытии позиции = объём заявки × расчётная цена ÷ кредитное плечо
```

- Расчётная цена для лимитной заявки — цена лимитной заявки, указанная пользователем.
- Расчётная цена для рыночной заявки — маркировочная цена на момент отправки заявки.

### Фактическая маржа при открытии позиции

```
Фактическая маржа при открытии позиции = Σ（объём каждой сделки × цена каждой сделки ÷ кредитное плечо）
```

### Ожидаемая стоимость открытия позиции

```
Ожидаемая стоимость открытия позиции = ожидаемая маржа при открытии позиции + ожидаемая комиссия за открытие позиции
```

### Фактическая стоимость открытия позиции

```
Фактическая стоимость открытия позиции = фактическая маржа при открытии позиции + фактическая комиссия за открытие позиции
```

### Фактическая комиссия за открытие позиции

```
Фактическая комиссия за открытие позиции = Σ（объём каждой сделки × цена каждой сделки × применимая ставка комиссии Maker/Taker）
```

## Расчёт прибыли и убытка

### Нереализованная прибыль и убыток

```
Длинная позиция: нереализованная прибыль и убыток =（маркировочная цена − средняя цена открытия）× объём позиции
Короткая позиция: нереализованная прибыль и убыток =（средняя цена открытия − маркировочная цена）× объём позиции
```

## Доступный объём открытия и использование средств

### Максимальный объём открытия позиции

```
Лимитная заявка: максимальный объём открытия позиции = доступный баланс ÷ [цена лимита ×（1 ÷ кредитное плечо + резервируемая ставка комиссии）]
Рыночная заявка: максимальный объём открытия позиции = доступный баланс ÷ [текущая маркировочная цена ×（1 ÷ кредитное плечо + резервируемая ставка комиссии）]
```

### Ожидаемая потребность в средствах на единицу

```
Ожидаемая потребность в средствах на единицу = расчётная цена ÷ кредитное плечо + расчётная цена × резервируемая ставка комиссии
```

## Показатели позиции и маржи

### Номинальная стоимость позиции

```
Номинальная стоимость позиции = объём позиции × средняя цена открытия
```

### Поддерживающая маржа

```
Поддерживающая маржа = номинальная стоимость позиции × ставка поддерживающей маржи текущего уровня риска
```

### Начальная маржа позиции

```
Начальная маржа позиции = номинальная стоимость позиции ÷ кредитное плечо
```

## Показатели счёта

### Баланс кошелька

```
Баланс кошелька = доступный баланс + заблокированный баланс
```

### Собственный капитал счёта

```
Собственный капитал счёта = баланс кошелька + вся нереализованная прибыль и убыток
```

## Расчёты, связанные с принудительной ликвидацией

### Комиссия за принудительную ликвидацию

```
Комиссия за принудительную ликвидацию = объём ликвидации × маркировочная цена на момент ликвидации × ставка комиссии за принудительную ликвидацию
```

### Теоретическая прибыль и убыток при принудительной ликвидации

```
Длинная позиция: теоретическая прибыль и убыток при ликвидации =（маркировочная цена на момент ликвидации − средняя цена открытия）× объём ликвидации
Короткая позиция: теоретическая прибыль и убыток при ликвидации =（средняя цена открытия − маркировочная цена на момент ликвидации）× объём ликвидации
```

### Справочная цена принудительной ликвидации

```
Длинная позиция: справочная цена ликвидации = средняя цена открытия ×（1 − 1 ÷ кредитное плечо + ставка поддерживающей маржи）
Короткая позиция: справочная цена ликвидации = средняя цена открытия ×（1 + 1 ÷ кредитное плечо − ставка поддерживающей маржи）
```

:::note
Фактически отображаемая цена принудительной ликвидации может отличаться от приведённых выше упрощённых справочных формул из-за комиссий, финансирования, изменений позиции, корректировок уровня риска, правил округления и других факторов счёта.
:::

## Процедура принудительной ликвидации в изолированном режиме

В изолированном режиме каждая позиция использует отдельную маржу. При устойчивом росте риска по определённой позиции и недостатке маржи принудительно ликвидирована может быть только эта изолированная позиция, что обычно не затрагивает напрямую другие изолированные позиции.

Конкретные условия срабатывания, порядок исполнения и результаты расчётов определяются актуальными параметрами риска, отображаемыми на торговой странице UXUY, и фактическими результатами исполнения.

| Шаг | Описание процедуры |
| --- | --- |
| 1. Устойчивый рост риска | Рыночная цена движется в неблагоприятном направлении, нереализованный убыток по позиции продолжает увеличиваться. |
| 2. Недостаток маржи | Когда маржи позиции недостаточно для соблюдения текущего требования по поддерживающей марже, система переходит к процедуре обработки риска. |
| 3. Срабатывание принудительной ликвидации | Система выполняет принудительную ликвидацию данной изолированной позиции в соответствии с применимыми правилами контроля риска. |
| 4. Исполнение позиции | Заявка на закрытие позиции направляется на рынок для исполнения; окончательная цена исполнения зависит от текущей рыночной ликвидности и фактических результатов исполнения. |
| 5. Расчёт прибыли и убытка | После закрытия позиции система рассчитывает окончательную прибыль и убыток, списывает применимые комиссии и обновляет активы счёта. |
