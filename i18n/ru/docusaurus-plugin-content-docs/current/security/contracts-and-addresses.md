# Адреса контрактов и инфраструктуры

На этой странице перечислены публично раскрытые адреса ончейн-контрактов и инфраструктуры системы бессрочных контрактов UXUY, что позволяет пользователям проверять ончейн-транзакции, движение средств и информацию о взаимодействии с протоколом. При выполнении ончейн-проверок или взаимодействий следует использовать только адреса, опубликованные в официальной документации UXUY.

:::danger Предупреждение о безопасности
Перед любым ончейн-взаимодействием внимательно сверяйте адрес, соответствующую сеть и данные официального блок-эксплорера. UXUY никогда не просит пользователей переводить средства на неизвестные адреса через личные сообщения и не запрашивает приватные ключи, сид-фразы или коды подтверждения.
:::
