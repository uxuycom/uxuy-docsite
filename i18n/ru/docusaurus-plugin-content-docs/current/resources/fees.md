# Комиссии

Комиссии платформы раскрываются отдельно по каждому продукту. Ниже приведены типы комиссий и ставки по каждому продукту.

| Продукт | Тип комиссии | Стандартный пользователь | Пользователи Agent |
| --- | --- | --- | --- |
| Торговля криптоактивами | Сервисный сбор или комиссия за исполнение | 0.50% | 0.10% |
| Бессрочные контракты | Комиссия Maker | 0.02% | 0.01% |
| Бессрочные контракты | Комиссия Taker | 0.06% | 0.03% |
| Бессрочные контракты | Комиссия за принудительную ликвидацию | Переменная | Переменная |
| Бессрочные контракты | Финансирование | Переменное | Переменное |
| Депозит | Комиссия за пополнение | Нет | Нет |
| Вывод средств | Сетевая комиссия и сервисный сбор | 0.30% | 0.30% |
| Акции и RWA | Торговая комиссия или сервисный сбор | 0.50% | 0.10% |

:::note
- Окончательным источником являются фактические комиссии, отображаемые на странице подтверждения перед отправкой сделки пользователем.
- Комиссия за вывод средств взимается только при необходимости кросс-чейн обработки стейблкоинов.
:::
