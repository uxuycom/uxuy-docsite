# Поддерживаемые сети

UXUY поддерживает пополнение, вывод средств и ончейн-взаимодействия в следующих блокчейн-сетях. Перечень поддерживаемых сетей может со временем изменяться; окончательным источником является информация, отображаемая в приложении.

| Сеть | Депозит | Вывод | GasLess | Восстановление активов |
| --- | --- | --- | --- | --- |
| Ethereum | Поддерживается | Поддерживается | См. [Правила GasLess](./gasless-rules.md) | Поддерживается |
| BNB Smart Chain | Поддерживается | Поддерживается | См. [Правила GasLess](./gasless-rules.md) | Поддерживается |
| Base | Поддерживается | Поддерживается | См. [Правила GasLess](./gasless-rules.md) | Поддерживается |
| Arbitrum One | Поддерживается | Поддерживается | См. [Правила GasLess](./gasless-rules.md) | Поддерживается |
| X Layer | Поддерживается | Поддерживается | См. [Правила GasLess](./gasless-rules.md) | Поддерживается |
| Solana | Поддерживается | Поддерживается | См. [Правила GasLess](./gasless-rules.md) | Обратитесь в службу поддержки |
| Polygon | Поддерживается | Поддерживается | См. [Правила GasLess](./gasless-rules.md) | Поддерживается |
| TRON | Поддерживается | Поддерживается | Не поддерживается | Обратитесь в службу поддержки |

:::note
Перечень сетей, поддерживающих восстановление активов, не полностью совпадает с перечнем сетей, поддерживающих депозиты и выводы. В текущем «Руководстве по восстановлению активов» в качестве сетей с поддержкой восстановления активов указаны opBNB, Arbitrum One, Optimism, BNB Smart Chain, Base, Ethereum и X Layer, однако это не означает, что каждая из указанных сетей поддерживает пополнение, вывод всех активов или все функции продукта.
:::
