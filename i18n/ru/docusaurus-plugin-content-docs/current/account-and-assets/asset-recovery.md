# Восстановление активов

Функция восстановления активов применима в отдельных случаях, например когда пользователь переводит поддерживаемый актив на счёт UXUY на смарт-контракте по ошибочному или неподдерживаемому маршруту пополнения.

## Что необходимо подтвердить перед отправкой заявки

- Хеш транзакции (Transaction Hash)
- Адрес контракта актива
- Сеть отправления и целевая сеть
- Целевой адрес
- Поддерживается ли текущая сеть инструментом восстановления активов UXUY

:::warning Предупреждение о безопасности
Никогда не сообщайте приватный ключ, сид-фразу или код подтверждения участникам сообщества либо неофициальным аккаунтам службы поддержки.
:::

Подробные инструкции см. в [«Руководстве по восстановлению активов»](../asset-recovery-guide.md).
