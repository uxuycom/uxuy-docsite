# Счёт средств

Счёт средств — это основной раздел, в котором пользователь просматривает и управляет поддерживаемыми активами UXUY.

Через счёт средств пользователь может:

- Просматривать балансы различных поддерживаемых активов
- Пополнять активы из внешнего кошелька или с торговой платформы
- Выводить активы на внешние адреса
- Переводить активы между доступными продуктовыми счетами UXUY
- При наличии доступа использовать поддерживаемые фиатные или сторонние каналы пополнения

Подробные инструкции по пополнению и выводу средств см. в разделе [Быстрый старт](../getting-started.md#deposits-and-withdrawals).
