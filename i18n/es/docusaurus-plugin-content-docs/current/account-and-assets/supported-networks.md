# Redes compatibles

UXUY admite depósitos, retiros e interacciones on-chain en las siguientes redes blockchain. El alcance de las redes compatibles puede variar con el tiempo; prevalecerá lo mostrado en la aplicación.

| Red | Depósito | Retiro | GasLess | Recuperación de activos |
| --- | --- | --- | --- | --- |
| Ethereum | Compatible | Compatible | Consulte [Reglas de GasLess](./gasless-rules.md) | Compatible |
| BNB Smart Chain | Compatible | Compatible | Consulte [Reglas de GasLess](./gasless-rules.md) | Compatible |
| Base | Compatible | Compatible | Consulte [Reglas de GasLess](./gasless-rules.md) | Compatible |
| Arbitrum One | Compatible | Compatible | Consulte [Reglas de GasLess](./gasless-rules.md) | Compatible |
| X Layer | Compatible | Compatible | Consulte [Reglas de GasLess](./gasless-rules.md) | Compatible |
| Solana | Compatible | Compatible | Consulte [Reglas de GasLess](./gasless-rules.md) | Contacte con el servicio de atención al cliente |
| Polygon | Compatible | Compatible | Consulte [Reglas de GasLess](./gasless-rules.md) | Compatible |
| TRON | Compatible | Compatible | No compatible | Contacte con el servicio de atención al cliente |

:::note
Las redes compatibles con la recuperación de activos no coinciden por completo con las redes compatibles con depósitos y retiros. La actual «Guía de recuperación de activos» incluye opBNB, Arbitrum One, Optimism, BNB Smart Chain, Base, Ethereum y X Layer como redes compatibles con la recuperación de activos, si bien esto no implica que todas ellas admitan depósitos, retiros o la totalidad de las funciones del producto para todos los activos.
:::
