# 资金账户

资金账户是用户查看和管理 UXUY 支持资产的主要入口。

用户可通过资金账户：

- 查看不同支持资产的余额
- 从外部钱包或交易平台充值资产
- 向外部地址提现资产
- 在可用的 UXUY 产品账户之间划转资产
- 在开放的情况下，使用支持的法币或第三方入金渠道

具体充值与提现操作步骤，详见 [快速开始](../getting-started.md#deposits-and-withdrawals)。
