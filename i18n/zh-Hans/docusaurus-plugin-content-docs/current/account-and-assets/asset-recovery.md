# 资产找回

资产找回功能适用于部分特定情形，例如用户通过错误或不受支持的充值路径，将支持的资产转入 UXUY 智能合约账户。

## 提交前请先确认

- 交易哈希（Transaction Hash）
- 资产合约地址
- 转出网络和目标网络
- 目标地址
- 当前网络是否受 UXUY 资产找回工具支持

:::warning 安全提示
切勿向社区成员或非官方客服账户提供私钥、助记词或验证码。
:::

详细操作步骤请参阅[《资产找回指南》](../asset-recovery-guide.md)。
