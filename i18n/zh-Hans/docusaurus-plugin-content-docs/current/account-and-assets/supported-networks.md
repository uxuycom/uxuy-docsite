# 支持的网络

UXUY 支持在以下区块链网络中进行充值、提现及链上交互。网络支持范围可能随时间调整，最终以 App 内展示为准。

| 网络 | 充值 | 提现 | GasLess | 资产找回 |
| --- | --- | --- | --- | --- |
| Ethereum | 支持 | 支持 | 见 [GasLess 规则](./gasless-rules.md) | 支持 |
| BNB Smart Chain | 支持 | 支持 | 见 [GasLess 规则](./gasless-rules.md) | 支持 |
| Base | 支持 | 支持 | 见 [GasLess 规则](./gasless-rules.md) | 支持 |
| Arbitrum One | 支持 | 支持 | 见 [GasLess 规则](./gasless-rules.md) | 支持 |
| X Layer | 支持 | 支持 | 见 [GasLess 规则](./gasless-rules.md) | 支持 |
| Solana | 支持 | 支持 | 见 [GasLess 规则](./gasless-rules.md) | 请联系客服 |
| Polygon | 支持 | 支持 | 见 [GasLess 规则](./gasless-rules.md) | 支持 |
| TRON | 支持 | 支持 | 不支持 | 请联系客服 |

:::note
资产找回支持的网络与充值/提现支持的网络不完全一致。当前《资产找回指南》将 opBNB、Arbitrum One、Optimism、BNB Smart Chain、Base、Ethereum 和 X Layer 列为支持资产找回的网络，但这并不代表上述每条网络都支持所有资产的充值、提现或全部产品功能。
:::
