# UXUY Wallet 项目合作公告

UXUY Wallet 围绕钱包及相关 DApp 应用开展生态合作，为项目方提供项目展示、直播互动及线下交流等支持，帮助用户了解生态项目。

资源展示及活动参与本身，不代表 UXUY Wallet 对相关项目作出投资、担保或收益承诺。合作范围以双方确认的具体事项为限。

## 合作形式

|合作形式|主要内容|
|---|---|
|DApp 热门展示|项目方可申请在钱包 DApp 热门区域展示项目，须提交相应资料并满足审核及合作条件。|
|Banner 展示|符合项目审核及相关合作条件的项目，可申请 Banner 展示。Banner 与 DApp 热门分别申请。|
|直播合作|项目方可自行开播，与 UXUY Wallet 配合开展用户互动及活跃度运营。|
|线下 AMA|符合相关合作条件的项目，可申请面向项目用户开展线下交流，具体时间、地点及安排由双方协商确定。|

不同资源适用不同的申请条件、展示周期及执行安排，项目方可向 UXUY Wallet 合作对接人了解。提交申请不代表已经获得合作资格或展示资源。展示位置和排序由运营安排，可在展示期间调整，不承诺固定名次或特定流量、用户增长及交易效果。

直播合作涉及由 UXUY Wallet 提供的体验金时，UXUY Wallet 承担其约定范围内的发放工作。具体金额、发放时间及使用限制应结合相应活动规则了解。

## 申请与审核

项目方可向 UXUY Wallet 合作对接人说明拟申请的资源，并按项目情况提供项目资料、DApp 入口、已部署合约信息及其他核验材料。涉及项目 LP 底池条件的申请，需提供所在链、池地址及相关资金核验信息。

申请 DApp 热门须提交覆盖当前部署合约的审计报告，并满足相应审计及产品核验要求。UXUY Wallet 将核验产品核心流程及相关资金退出路径；其他资源是否需要审计报告，按项目情况确定。上述审核和核验用于合作准入判断，不构成对项目持续安全、合法合规或资金退出的保证。

审核通过后，双方确认具体合作事项和执行安排，按实际排期推进，并结合资源类型核对合作效果、沟通后续安排。

## 合作范围与责任

UXUY Wallet 提供双方确认范围内的展示、用户运营及活动支持。项目方应对其提供的项目资料、宣传内容、产品、合约及相关服务承担依法应负的责任。项目方的观点、言论及行为不代表 UXUY Wallet 的官方立场。

项目审核、审计报告核验、资源展示，以及相关人员参与直播或 AMA，不构成对项目安全、合规状况、资产价值、资金退出或投资回报的保证，亦不构成投资推荐。不能仅凭上述合作认定 UXUY Wallet 是相关项目的发行方、运营方或担保方；各方关系及责任仍需结合实际安排判断。

本说明涉及的项目 LP 底池资金由项目方或用户自行提供并控制，UXUY Wallet 不控制该底池资金。此项说明仅针对上述合作底池。

上述说明不免除 UXUY Wallet 对其明确承担的展示、体验金发放等事项的履约义务，也不排除或限制任何一方依法不得排除或限制的责任。

## 参与提示

用户在访问或参与第三方项目之前，应了解项目的服务提供方、适用规则、合约权限、费用及资金退出条件。数字资产及相关项目可能涉及价格波动、智能合约漏洞、流动性不足、项目运营变化及资金损失等风险，展示和活动支持不能替代对具体项目的判断。

网页可访问不代表相关服务或活动在用户所在地可提供或可参与；具体参与范围受适用法律及相关参与条件约束。
