# 永续合约概览

永续合约允许用户在没有固定到期日的情况下，对支持的市场建立多头或空头仓位。

- 当市场价格上涨时，多头仓位可能获得收益。
- 当市场价格下跌时，空头仓位可能获得收益。
- 杠杆可在相同保证金投入下放大市场敞口，同时也会同步放大风险。
- 当仓位无法满足维持保证金要求时，可能触发强制平仓。
- 资金费率机制用于使永续合约价格尽量贴近标的市场价格。

## 交易前须知

下单前，请确认以下信息：

- 合约品种及持仓方向
- 订单类型及委托价格
- 仓位数量
- 杠杆倍数
- 预计保证金和开仓手续费
- 预计强平价格
- 资金费率与结算

## 订单计价说明

在估算保证金时：

- **限价单**的计算价格：用户输入的限价委托价格。
- **市价单**的计算价格：订单提交时的标记价格。

实际保证金和手续费将根据实际成交数量、成交价格、杠杆倍数，以及适用的 Maker 或 Taker 手续费率计算。

## 核心数据定义

| 术语 | 说明 |
| --- | --- |
| 标记价格（Mark Price） | 用于计算未实现盈亏、监控保证金状态及进行强平相关计算的参考价格。 |
| 平均开仓价格（Entry Price） | 当前持仓各笔成交价格按成交量加权后的平均价格。 |
| 仓位名义价值（Position Notional） | 仓位数量乘以相应参考价格得到的名义价值。 |
| 初始保证金（Initial Margin） | 建立并维持初始仓位敞口所需的保证金。 |
| 维持保证金（Maintenance Margin） | 维持仓位不被强制平仓所需的最低保证金。 |
| 账户权益（Account Equity） | 钱包余额与全部未实现盈亏之和。 |
| 资金费率（Funding Rate） | 多头与空头之间按照固定周期进行资金交换时使用的费率。 |
| 风险档位（Risk Tier） | 根据仓位名义价值划分的风险等级，用于确定最高可用杠杆、维持保证金率及其他风险参数。 |
| 保险基金（Insurance Fund） | 用于在极端行情下承担部分强平穿仓损失，并降低自动减仓（ADL）触发概率的风险保障机制。 |
| 自动减仓（ADL） | 当强平损失无法由保险基金充分覆盖时，平台可能按照风险排序自动减少部分盈利仓位的最后一级风险控制机制。 |
