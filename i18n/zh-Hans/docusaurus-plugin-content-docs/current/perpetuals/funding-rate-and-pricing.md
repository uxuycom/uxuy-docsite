# 资金费率与定价机制

## 标记价格

### 什么是标记价格

标记价格是平台用于计算未实现盈亏、监控仓位风险及判断是否触发强制平仓的重要参考价格。标记价格并不等同于最新成交价。

### 为什么使用标记价格

市场可能因短时间内的异常成交或流动性变化而出现剧烈波动。若直接使用最新成交价进行风险计算，可能造成非必要的强平触发。平台因此采用相对稳定的标记价格作为风险管理依据。

### 标记价格的主要用途

- 计算未实现盈亏
- 判断是否满足强制平仓条件
- 监控仓位与账户风险
- 计算部分风险指标

### 标记价格是否影响成交

不会。订单仍按照市场实际可成交价格进行撮合，标记价格主要用于盈亏与风险计算，不直接参与订单撮合。

## 指数价格

指数价格根据有效参考交易平台的价格及其分配权重计算。

```
指数价格 = Σ（有效交易平台价格 × 原始权重）÷ 有效权重总和
```

如某一参考来源失效或暂时不可用，平台可根据指数计算方法，将其从当前有效计算中排除。

## 资金费率

### 什么是资金费率

资金费率是永续合约市场中，多头与空头之间按照规定周期支付或收取的一项费用。资金费用由交易双方根据费率方向进行转移，通常不构成平台交易手续费收入。

### 为什么需要资金费率

永续合约没有固定到期日。资金费率机制通过多空双方之间的定期支付，促进永续合约价格与标的现货市场价格保持相对一致。

### 资金费率公式

```
资金费率（F）= 平均溢价指数（P）+ clamp（基础利率 − 平均溢价指数（P），−0.0005，0.0005）
```

- 当 F &gt; 0 时，多头向空头支付资金费用。
- 当 F &lt; 0 时，空头向多头支付资金费用。

### 资金费用何时结算

平台将在规定的资金费用结算时间进行结算。只有在结算时仍持有相关仓位的用户，才会参与当期资金费用的支付或收取；已在结算前完全平仓的仓位不参与本次结算。

:::note
不同币种费率随市场情况动态调整，具体内容以资产详情页展示为准。
:::
