# 快速开始

## 下载与注册

请仅通过 UXUY 官方网站或经验证的应用商店页面下载 UXUY，避免使用非官方渠道分享的安装链接。

官方下载地址：[https://www.uxuy.com/download](https://www.uxuy.com/download)

### 创建账户

UXUY 支持以下登录方式：

- Apple ID
- Google 账户
- 邮箱验证码

请按照页面提示完成账户创建，并进入 UXUY App。

:::warning 安全提示
- 确认当前访问的是 UXUY 官方域名或官方应用。
- 切勿向任何人透露验证码、私钥、助记词或账户恢复信息。
- UXUY 官方客服不会要求用户向陌生地址转入资产。
:::

## 充值与提现 {#deposits-and-withdrawals}

### 充值资产

1. 打开 UXUY，进入【资产】或【资金】页面。
2. 选择【充值】。
3. 选择需要充值的资产和网络。
4. 复制充值地址，或扫描二维码。
5. 从外部钱包或交易平台向该地址转入资产。

:::danger 重要提示
请务必确认 UXUY 选择的资产和网络与转出平台完全一致。通过不支持的网络充值，可能导致到账延迟，甚至造成资产无法找回。
:::

### 提现资产

1. 打开 UXUY，进入【资产】或【资金】页面。
2. 选择【提现】。
3. 选择需要提现的资产和网络。
4. 填写收款地址和提现数量。
5. 确认网络、费用及收款地址无误后提交。

提现功能是否开放、处理时间及相关费用，可能因资产和网络而异。

## 完成第一笔交易

1. 向 UXUY 账户充值支持的资产。
2. 进入【交易】页面。
3. 选择需要交易的市场或资产。
4. 输入交易数量。
5. 查看预计成交价格、手续费、滑点及执行路由。
6. 确认并提交交易。
7. 在订单历史或链上交易记录中查看交易结果。

:::note
使用杠杆产品前，请充分了解保证金、强平和资金费率等信息。详见 [永续合约](./perpetuals/overview.md)。
:::
