# 交易

## 交易概览

UXUY 通过统一界面，为用户提供多种链上市场的交易入口。

## 加密资产交易

用户可使用账户中的可用稳定币余额交易支持的加密资产。UXUY 可能在不同支持网络和流动性来源之间进行路由，以寻找可执行的交易路径。

确认交易前，请重点核对：

- 预计成交价格
- 价格影响和滑点
- 交易费用与网络费用
- 最低可得数量
- 所选执行路由和网络

## 永续合约

用户可使用保证金和杠杆交易永续合约。永续合约没有固定到期日，但持仓可能产生资金费用；当账户保证金不足时，仓位可能被强制平仓。

完整规则详见 [永续合约](./perpetuals/overview.md)。

## 股票与 RWA

UXUY 为用户提供支持的股票挂钩资产及现实世界资产（RWA）链上市场入口。不同产品的交易时间、流动性、价格形成机制、结算结构及地区可用性可能存在差异。

:::note
在主要市场的非交易时段，流动性可能降低，买卖价差或价格影响可能增大。
:::

## 跟单交易

跟单交易允许用户关注符合条件的交易员，并按照用户设定的跟单参数，自动复制其选定的交易行为。

跟单功能是否开放及其执行基础设施，以当前 UXUY App 中展示的产品版本为准。
