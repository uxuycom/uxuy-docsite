# 시작하기

## 다운로드 및 가입

UXUY는 반드시 공식 웹사이트 또는 검증된 앱스토어 페이지를 통해서만 다운로드하시고, 비공식 경로로 공유된 설치 링크는 사용하지 마십시오.

공식 다운로드 주소: [https://www.uxuy.com/download](https://www.uxuy.com/download)

### 계정 생성

UXUY는 다음 로그인 방식을 지원합니다.

- Apple ID
- Google 계정
- 이메일 인증 코드

화면 안내에 따라 계정 생성을 완료한 후 UXUY App으로 진입하십시오.

:::warning 보안 유의사항
- 현재 접속 중인 곳이 UXUY 공식 도메인 또는 공식 애플리케이션인지 확인하십시오.
- 인증 코드, 개인 키, 니모닉 구문, 계정 복구 정보를 누구에게도 알려주지 마십시오.
- UXUY 공식 고객 지원은 사용자에게 알 수 없는 주소로 자산을 이전하도록 요구하지 않습니다.
:::

## 입금 및 출금 {#deposits-and-withdrawals}

### 자산 입금

1. UXUY를 실행하고 【자산】 또는 【자금】 페이지로 이동합니다.
2. 【입금】을 선택합니다.
3. 입금할 자산과 네트워크를 선택합니다.
4. 입금 주소를 복사하거나 QR 코드를 스캔합니다.
5. 외부 지갑 또는 거래 플랫폼에서 해당 주소로 자산을 전송합니다.

:::danger 중요 안내
UXUY에서 선택한 자산과 네트워크가 출금하는 플랫폼과 완전히 일치하는지 반드시 확인하십시오. 지원되지 않는 네트워크로 입금하는 경우 입금 지연이 발생하거나 자산을 복구할 수 없게 될 수 있습니다.
:::

### 자산 출금

1. UXUY를 실행하고 【자산】 또는 【자금】 페이지로 이동합니다.
2. 【출금】을 선택합니다.
3. 출금할 자산과 네트워크를 선택합니다.
4. 수취 주소와 출금 수량을 입력합니다.
5. 네트워크, 수수료 및 수취 주소에 오류가 없는지 확인한 후 제출합니다.

출금 기능의 제공 여부, 처리 시간 및 관련 수수료는 자산과 네트워크에 따라 다를 수 있습니다.

## 첫 거래 완료하기

1. UXUY 계정으로 지원 자산을 입금합니다.
2. 【거래】 페이지로 이동합니다.
3. 거래할 시장 또는 자산을 선택합니다.
4. 거래 수량을 입력합니다.
5. 예상 체결 가격, 수수료, 슬리피지 및 실행 라우팅을 확인합니다.
6. 내용을 확인한 후 거래를 제출합니다.
7. 주문 내역 또는 온체인 거래 기록에서 거래 결과를 확인합니다.

:::note
레버리지 상품을 이용하기 전에 증거금, 강제 청산, 펀딩 비율 등의 내용을 충분히 이해하십시오. 자세한 내용은 [무기한 선물](./perpetuals/overview.md)을 참조하십시오.
:::
