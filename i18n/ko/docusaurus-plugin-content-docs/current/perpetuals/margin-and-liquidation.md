# 증거금, 손익 및 강제 청산 메커니즘

:::info
문서 내용과 UXUY 거래 화면에 표시된 내용이 상이한 경우, 제품 화면의 실시간 데이터와 규칙을 기준으로 합니다. 실제 계산에는 제품별 소수점 정밀도 및 반올림 규칙, 수수료 예약분, 펀딩 비용, 리스크 티어 등의 파라미터가 추가로 반영될 수 있습니다.
:::

## 진입 증거금과 비용

### 예상 진입 증거금

```
예상 진입 증거금 = 주문 수량 × 산정 가격 ÷ 레버리지 배수
```

- 지정가 주문의 산정 가격은 사용자가 입력한 지정가 주문 가격입니다.
- 시장가 주문의 산정 가격은 주문 제출 시점의 마크 가격입니다.

### 실제 진입 증거금

```
실제 진입 증거금 = Σ（각 체결 수량 × 각 체결 가격 ÷ 레버리지 배수）
```

### 예상 진입 비용

```
예상 진입 비용 = 예상 진입 증거금 + 예상 진입 수수료
```

### 실제 진입 비용

```
실제 진입 비용 = 실제 진입 증거금 + 실제 진입 수수료
```

### 실제 진입 수수료

```
실제 진입 수수료 = Σ（각 체결 수량 × 각 체결 가격 × 적용되는 Maker/Taker 수수료율）
```

## 손익 계산

### 미실현 손익

```
롱 포지션：미실현 손익 =（마크 가격 − 평균 진입 가격）× 포지션 수량
숏 포지션：미실현 손익 =（평균 진입 가격 − 마크 가격）× 포지션 수량
```

## 진입 가능 수량과 자금 점용

### 최대 진입 가능 수량

```
지정가 주문：최대 진입 가능 수량 = 사용 가능 잔액 ÷ [지정가 ×（1 ÷ 레버리지 배수 + 예약 수수료율）]
시장가 주문：최대 진입 가능 수량 = 사용 가능 잔액 ÷ [현재 마크 가격 ×（1 ÷ 레버리지 배수 + 예약 수수료율）]
```

### 단위당 예상 소요 자금

```
단위당 예상 소요 자금 = 산정 가격 ÷ 레버리지 배수 + 산정 가격 × 예약 수수료율
```

## 포지션 및 증거금 지표

### 포지션 명목 가치

```
포지션 명목 가치 = 포지션 수량 × 평균 진입 가격
```

### 유지 증거금

```
유지 증거금 = 포지션 명목 가치 × 현재 리스크 티어에 해당하는 유지 증거금률
```

### 포지션 개시 증거금

```
포지션 개시 증거금 = 포지션 명목 가치 ÷ 레버리지 배수
```

## 계정 지표

### 지갑 잔액

```
지갑 잔액 = 사용 가능 잔액 + 동결 잔액
```

### 계정 순자산

```
계정 순자산 = 지갑 잔액 + 전체 미실현 손익
```

## 강제 청산 관련 계산

### 강제 청산 수수료

```
강제 청산 수수료 = 청산 수량 × 청산 시점 마크 가격 × 강제 청산 수수료율
```

### 이론상 강제 청산 손익

```
롱 포지션：이론상 강제 청산 손익 =（청산 시점 마크 가격 − 평균 진입 가격）× 청산 수량
숏 포지션：이론상 강제 청산 손익 =（평균 진입 가격 − 청산 시점 마크 가격）× 청산 수량
```

### 참고 강제 청산 가격

```
롱 포지션：참고 강제 청산 가격 = 평균 진입 가격 ×（1 − 1 ÷ 레버리지 배수 + 유지 증거금률）
숏 포지션：참고 강제 청산 가격 = 평균 진입 가격 ×（1 + 1 ÷ 레버리지 배수 − 유지 증거금률）
```

:::note
화면에 실제로 표시되는 강제 청산 가격은 수수료, 펀딩 비용, 포지션 변동, 리스크 티어 조정, 반올림 규칙 및 기타 계정 요인으로 인해 위의 단순화된 참고 산식과 상이할 수 있습니다.
:::

## 격리 마진 모드 강제 청산 절차

격리 마진 모드에서는 각 포지션마다 독립된 증거금이 사용됩니다. 특정 포지션의 리스크가 지속적으로 상승하고 증거금이 부족해지는 경우, 해당 격리 포지션만 강제 청산될 수 있으며 일반적으로 다른 격리 포지션에는 직접적인 영향을 미치지 않습니다.

구체적인 발생 조건, 집행 방식 및 정산 결과는 UXUY 거래 페이지에 표시된 실시간 리스크 파라미터와 실제 체결 결과를 기준으로 합니다.

| 단계 | 절차 설명 |
| --- | --- |
| 1. 리스크 지속 증가 | 시장 가격이 불리한 방향으로 변동하여 포지션의 미실현 손실이 지속적으로 확대됩니다. |
| 2. 증거금 부족 | 포지션 증거금이 현재 유지 증거금 요건을 충족하지 못하는 경우, 시스템이 리스크 처리 절차에 진입합니다. |
| 3. 강제 청산 발생 | 시스템이 적용되는 리스크 관리 규칙에 따라 해당 격리 포지션에 대해 강제 청산을 실행합니다. |
| 4. 포지션 체결 | 청산 주문이 시장에 제출되어 실행되며, 최종 체결 가격은 당시의 시장 유동성과 실제 체결 상황에 따라 결정됩니다. |
| 5. 손익 정산 | 포지션이 종료된 후 시스템이 최종 손익을 산정하고 적용 수수료를 차감한 뒤 계정 자산을 갱신합니다. |
