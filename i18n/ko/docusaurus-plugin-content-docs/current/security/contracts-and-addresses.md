# 컨트랙트 및 인프라 주소

:::danger 보안 유의사항
온체인 상호작용을 수행하기 전에 주소, 해당 네트워크 및 공식 블록 탐색기 정보를 반드시 대조하여 확인하십시오. UXUY는 개인 메시지를 통해 사용자에게 알 수 없는 주소로의 송금을 요구하지 않으며, 개인 키, 니모닉 구문 또는 인증 코드를 요구하지 않습니다.
:::
