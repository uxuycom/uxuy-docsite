# 자산 복구

자산 복구 기능은 사용자가 잘못된 경로 또는 지원되지 않는 입금 경로를 통해 지원 자산을 UXUY 스마트 컨트랙트 계정으로 전송한 경우 등 일부 특정 상황에 적용됩니다.

## 신청 전 확인 사항

- 트랜잭션 해시(Transaction Hash)
- 자산 컨트랙트 주소
- 출금 네트워크 및 목적지 네트워크
- 목적지 주소
- 해당 네트워크가 UXUY 자산 복구 도구에서 지원되는지 여부

:::warning 보안 유의사항
커뮤니티 구성원이나 비공식 고객 지원 계정에 개인 키, 니모닉 구문 또는 인증 코드를 절대 제공하지 마십시오.
:::

자세한 절차는 [《자산 복구 가이드》](../asset-recovery-guide.md)를 참조하십시오.
